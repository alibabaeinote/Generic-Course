مرحلهٔ **برنامه‌ریزی و تثبیت محتوا** (Milestone 0). هنوز کدی نوشته نشده است.

## اصل حاکم بر پروژه

> این دوره وعدهٔ «دیزاینر شدن در دو ماه» نمی‌دهد. وعدهٔ اصلی، کاهش سردرگمی و ساختن یک مسیر روشن از
> **آگاهی → مهارت → میدان واقعی کار** است. این اصل باید در محتوا و تجربهٔ هر سه فاز حفظ شود.
